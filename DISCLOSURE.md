# Public evidence and responsible disclosure

This public portfolio is intentionally **not a code dump**. The owner maintains private implementation repositories that may contain confidential business details, infrastructure configuration, security-sensitive interfaces, licensed data, private issues or third-party work. Making one private GitHub repository public would expose its commit history and assets, not just its latest README. No original repository visibility was changed while preparing this showcase.

**Publication rules**

- Document user-visible behavior and substantiated engineering outcomes, not credentials, tokens, endpoints hidden from the public, secret architecture diagrams or customer-only information.
- Label deployed demos, field-tested functionality, unit tests, proof-of-concepts and proposed features separately.
- Never present a simulator as a real production customer, business interest as booked revenue, or machine-transcribed text as human-approved scholarship.
- Do not publish individual customers, device IPs, installation details, datasets under uncertain rights, model keys, project secrets or partner deliverables.
- The showcased educational datasets are described, not mirrored or relicensed.
- Source-code access, if appropriate, requires separate owner authorization and a security/licensing review.
